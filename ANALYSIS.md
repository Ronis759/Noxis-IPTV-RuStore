# Анализ проекта Noxis IPTV

Дата анализа: 12 ноября 2026 года

## Проект
- Android-приложение для Android TV / ТВ-боксов.
- Kotlin + AndroidX Media3 ExoPlayer 1.8.0.
- Gradle 8.9; Android Gradle Plugin 8.7.3; Kotlin 1.9.24.
- applicationId: `app.iptv.tv`.
- Версия 2.4.0, versionCode локально 1.
- Совместимость: Android 5.0+ (`minSdk 21`), target/compile SDK 35.

## Возможности
HTTP/HTTPS, HLS, MPEG-TS, UDP multicast и RTSP; импорт M3U/XMLTV; каналы, группы, избранное, история, архив/catch-up; настройки, резервное копирование, темы, таймер сна; обновления из GitHub Releases; управление пультом Android TV.

## Структура
- `MainActivity.kt` — основной экран, UI, пульт и плеер; очень большой файл (~156 КБ).
- `Iptv.kt` — сеть и разбор M3U/XMLTV.
- `Repository.kt` — серверы, плейлист, EPG и кэш.
- `EpgCache.kt` — кэш телепрограммы.
- `PrefSet.kt` — избранное и скрытые группы.
- `UpdateFlow.kt`, `Updater.kt`, `Integrity.kt` — обновления и SHA-256.
- `SettingsBackup.kt` — импорт/экспорт настроек.
- `SleepTimer.kt` — таймер сна.

## Замечания
1. В архиве нет `servers.txt`, только пример; реальные ссылки не должны попадать в репозиторий.
2. Это плеер, а не готовый IPTV-сервис с каналами.
3. `MainActivity.kt` лучше постепенно разделить на отдельные части.
4. `BUG_ANALYSIS.md` и `CHANGES_DETAIL.md` — документы из архива; их выводы нужно подтверждать текущим кодом.
5. Для автообновления нужен постоянный ключ подписи и `github_repo`.
